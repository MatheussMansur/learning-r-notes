# learning-r-notes

My notes and practice scripts from the "Análise de Dados em Linguagem R" course
(Escola Virtual.Gov / Enap, content by Ministério da Fazenda, 20h).

| Folder | Topic |
|---|---|
| 01-intro-data-analysis | big data, data science, machine learning, the data science process |
| 02-r-fundamentals | RStudio, data structures, loops, functions, apply, plots, dplyr |
| 03-machine-learning | linear regression, KNN, decision trees, k-means, train/test, cross-validation |
| 04-practice | travel expenses analysis and a diabetes prediction model |

The course practice is done in videos, so the scripts here are my own versions of what each module covers.

Run a script with `Rscript <file>.R`. Packages used: dplyr, ggplot2, class, rpart.
